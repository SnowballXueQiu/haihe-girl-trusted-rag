- 模型元数据内含个人联系方式。验收记录不得抄录具体号码；交付前须确认公开范围，并对截图和授权附件中的非必要个人信息脱敏。

## 导出前

本节仅适用于需要由权利人从 `model01.vroid` 重新导出的情形。现有新 VRM 的元数据声明禁止修改，不应由项目组擅自二次编辑或重新发布修改版。

- 用 VRoid Studio 打开 `海河少女/model01.vroid`，确认衣服、纹理、发饰和风筝道具不含未授权素材。
- 在表情页分别预览中性、眨眼、张口 `Aa/A`、微笑；检查牙齿、舌头、眼睑和头发穿模。
- 预览头部左右转动、上下视线、两侧手臂和腰部，确认骨骼与摆动参数正常。

## 导出设置

- 优先导出 VRM 1.0；系统同时兼容 VRM 0.x。
- 用于单人半身镜头，建议先保持原始质量；若浏览器帧率不稳定，再减少材质数和纹理分辨率，不先破坏表情和头发。
- 标题填写“海河少女”，作者填写参赛者真实姓名；根据比赛展示范围设置商用、修改、再分发、署名和成年内容权限。
- 如果参赛者不是模型全部权利人，不得自行把作者字段改为参赛者；名称、作者和许可必须由实际权利人确认后填写。
- 不使用未确认的签名、学校名或许可协议占位。

## 文件落位

导出后命名为：

```text
frontend/public/models/haihe-girl.vrm
```

然后执行：

```bash
uv run python scripts/validate_vrm.py
npm --prefix frontend run build
```
