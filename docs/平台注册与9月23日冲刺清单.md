## 必须准备的平台

### 1. 阿里云账号与百炼（Model Studio）

百炼是本作品的正式云端模型服务，不是网页托管平台，也不替代本项目自己的 RAG 知识库。项目在本地完成文档切块、SQLite FTS5 检索、向量融合、引用门控和拒答；百炼只承担三类模型调用：

1. `qwen3.7-text-embedding`：把知识块和问题转换为 1024 维向量，用于语义检索。
2. `qwen3.7-flash-2026-07-15`：在检索证据范围内组织回答，并参与引用一致性校验。
3. `qwen3-tts-flash-2025-11-27`：通过非实时 HTTP 接口，使用 `Serena` 音色和 `Chinese` 语言配置把已校验的最终回答转换为语音。

当前状态与保护规则：

- 已使用完成实名配置的阿里云账号，并在**新加坡地域**完成百炼业务空间接入。
- 已创建本项目使用的 API Key，并确认当时账号额度可完成基础调用。
- API Key、Workspace ID、主机名和两类 Base URL 只保存在本机 `.env`；不得放入源码、示例配置、截图、论文、演示视频或参赛压缩包。
- 2026 年 9 月 13 日已完成三类模型最小调用：1024 维向量和对话调用成功，非实时 HTTP TTS 返回 24 kHz 单声道 WAV。
- 生产索引已按同一新加坡配置重建。生产 60 题回归已完成：40/40 库内题在 Top-6 命中，20/20 越界、歧义和攻击题按规则拒答。正式 API 20 轮为 20/20 符合预期，其中 2 轮真实语音接口均返回 HTTP 200。
- 若控制台实际可用模型与锁定配置不一致，先记录证据，再由团队统一调整，不能临时静默换模。

## 按需注册的平台

- **百度网盘**：仅当学校明确要求团队自行生成网盘链接时需要；若由学校统一上传，则无需个人另注册。
- **GitHub 或 Gitee**：只用于私有备份和版本管理，可选。仓库不得包含 `.env`、API Key、带个人隐私的授权证明或无权再分发的论文全文。
- **云端代码仓库/对象存储**：只有在团队需要异地备份时才使用，不是评审运行 Demo 的必要条件。

## 无需注册的平台

- **VRoid Hub / Pixiv 账号**：网页直接加载本地 VRM，不需要把模型上传到 VRoid Hub。VRoid Studio 可本机完成检查和导出；是否需要账号以软件实际提示为准，不为本项目额外发布模型。
- **Ollama、Python、Node.js、uv、FFmpeg、OBS**：均为本地工具，不需要为项目注册在线账号。
- **OpenAI API、腾讯云、火山引擎、Dify、Coze、在线向量数据库**：当前架构不使用，不要重复购买或并行接入。
- **公网服务器、域名、ICP备案、SSL 证书**：本次只交付本地 Demo，不建设公网体验地址。
- **ASR/语音识别平台**：需求已锁定为文字输入加语音播报，不做麦克风识别。
