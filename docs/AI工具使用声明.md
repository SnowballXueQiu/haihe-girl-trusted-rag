# 海河少女可信 RAG 虚拟主播 AI 工具使用声明

## 作品基本信息

- 作品名称：海河少女 基于可信 RAG 的天津文化 AI 虚拟主播系统
- 申报方向：方向 A AI 智能体创作系统设计
- 学校：天津师范大学；作者：晏妍、王彦翔；指导教师：王欣雨

## AI 工具及具体作用

1. 阿里云百炼千问文本生成模型：只在检索完成后，根据系统提供的知识片段组织中文回答，并按结构返回逐段引用 ID。
2. 阿里云百炼文本向量模型：将人工审核后的知识块转换为向量，用于语义检索。
3. 阿里云百炼千问 TTS：将已经通过引用和事实一致性校验的最终回答转换为语音。
4. Ollama 本地模型：用于开发阶段接口联调、检索评测和提示词规则测试，不作为最终作品事实来源。
5. Codex：辅助代码实现、测试脚本、文档结构和工程排错。所有生成代码、文字和界面均由参赛团队检查、修改和最终确认。
6. VRoid Studio：属于三维角色制作工具，不负责自动生成知识性回答；参赛团队自行完成角色造型、纹理和参数调整。

## 人机协作边界

- 角色立意、文化主题、视觉选择、知识范围和最终表达由参赛团队确定。
- AI 不负责判断资料是否权威。资料入库前由人核对来源、页码、发布者和使用边界。
- AI 输出不能直接进入最终作品。程序先检查引用 ID，再进行第二轮证据一致性核验；未通过时改为拒答。
- 角色世界观属于艺术创作，系统在知识库中将其与历史事实分开标注。
- 参赛团队对作品原创性、版权、事实准确性、模型配置和最终提交内容承担责任。

## 数据与隐私

系统不收集用户身份信息，不保存对话历史，不将 API Key 写入代码或参赛包。运行时不启用联网搜索，仅把用户问题和检索到的必要知识片段发送给已配置的模型服务。

## 局限性声明

本作品不能证明大语言模型在所有情况下绝对不会产生幻觉。作品采用的是可检查的工程约束：限定知识边界、证据门控、有效引用、二次核验和证据不足时拒答。最终验收以测试集内不出现无依据事实回答为目标。
