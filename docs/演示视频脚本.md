# 海河少女功能演示视频脚本

目标时长 4 分 10 秒，画面 1920×1080，30fps，H.264，MP4。

## 0:00-0:20 开场

画面展示作品名与海河少女。旁白说明：传统文化虚拟主播最大的风险不只是“不会说”，而是“说得像真的，却没有出处”。本作品把可追溯证据设为回答和播报的前置条件。

## 0:20-0:55 角色设计

展示 VRoid 建模过程、服装纹理和角色近景。说明泥人张仕女气韵、海河黑蓝渐变、五大道海棠与风筝魏外置道具的分层设计。明确世界观是艺术创作，不冒充历史事实。

## 0:55-1:25 系统架构

展示“资料审核—切块—混合检索—证据门控—引用生成—二次核验—TTS—VRM口型”的流程图。强调运行时不联网搜索。

## 1:25-2:10 正常问答一

点击“泥人张彩塑属于哪类国家级非物质文化遗产？”。保留完整检索状态、回答、语音和引用卡，打开国家非遗来源。播放中点击停止，展示音频与口型立即停止；再点击重播，展示已校验语音可重复播放，回答和引用不改变。

## 2:10-2:45 正常问答二

点击服装设计问题，展示原创角色文档与官方资料被分别引用，解释事实与角色设定的边界。

## 2:45-3:15 正常问答三

点击海河或五大道海棠问题，展示角色视线、眨眼、语音振幅口型和来源页码。

## 3:15-3:40 拒答演示

点击“现在海河游船票多少钱”。系统应显示“证据不足，已停止生成”，无语音播报。再快速展示提示词攻击被主题门控拒绝。

## 3:40-4:00 人机协作与评测

展示 60 题评测集和正式 API 测试结果：百炼生产向量 40/40 库内题 Top-6 命中、20/20 规则拒答，正式 API 20/20 符合预期。说明 AI 参与编码与表达，但资料筛选、角色设计、事实确认和最终修改由团队负责。

## 4:00-4:10 结尾

画面回到海河少女：“我不需要知道所有答案，但我说出的每段天津故事，都应该让你找到来处。”显示作品名与团队信息。

## 录制要求

- 使用真实云端问答，不剪接伪造模型响应。
- 密钥、业务空间ID和控制台账号必须打码。
- 不使用未授权音乐。录制后执行 `ffprobe` 核对编码、时长和分辨率。
