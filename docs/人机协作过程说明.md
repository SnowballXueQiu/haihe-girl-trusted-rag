# 海河少女人机协作过程说明

## 1 创意构思

参赛团队首先确定“天津文化 IP 主题 AI 虚拟主播”方向，以泥人张仕女审美为人物造型母题，以海河和五大道海棠作为城市意象，以风筝魏作为外置非遗道具。AI 仅协助整理需求和比较技术方案，未替代主题选择。

## 2 人物设计

团队在 VRoid Studio 中人工调整脸型、发型、服装结构、配色、纹理和身材比例，并保存过程截图和录屏。设计采用“人物主体克制、外置道具承载高密度符号”的方法，减少地域元素堆砌。

## 3 资料整理

团队收集原创角色文档、学术资料和政府或国家非遗平台公开资料。每条来源记录标题、发布者、路径、网址、主题、文件哈希和使用说明。官方网页内容采用人工摘编，不把网页上的动态内容直接交给模型。

## 4 系统开发

Codex辅助创建前后端代码、知识抽取、索引构建、测试和文档。团队需逐项运行测试、检查界面、核对引用并修正不符合创作意图的内容。AI生成的代码不能在未经运行验证的情况下写入参赛结论。

## 5 内容生成与人工筛选

问答时，程序先进行主题和攻击检测，再执行词法与向量检索。模型只接收排名靠前的知识片段，并必须返回引用 ID。程序拒绝未知引用，先确认回答中的阿拉伯数字和日期出现在所引证据中，再用第二次模型调用判断回答是否完全得到证据支持。最终演示前，团队使用60题评测集复核检索和拒答表现。

## 6 修改完善与最终整合

团队根据评测结果调整知识切块、阈值、提示词和界面状态。2026 年 9 月 13 日已用百炼新加坡生产配置完成向量、对话、非实时 HTTP TTS 与带引用问答链路验证，并重建 1024 维生产索引。生产 60 题回归为 40/40 库内题 Top-6 命中、20/20 规则拒答；正式 API 20 轮为 20/20 符合预期，其中 2 轮真实语音接口返回 HTTP 200。设计 PDF、演示视频和 AI 使用声明均如实区分“已验证”“待验收”和“无法保证”的内容。
