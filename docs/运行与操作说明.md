# 海河少女可信 RAG 虚拟主播运行与操作说明

## 1 运行目标

程序在参赛者的 Mac 上启动，通过浏览器展示三维角色、文字问答、检索依据、引用页码和语音播报。程序不在运行时搜索互联网，只调用配置的模型服务处理已经收录的知识块。

当前执行硬截止为 **2026 年 9 月 23 日**，9 月 22 日完成版本冻结、复测、打包和验包。

## 2 环境要求

- 推荐演示设备：Apple Silicon Mac，内存 16GB 以上，Chrome 最新稳定版。
- Python 3.11 以上，由 `uv` 管理隔离环境。
- Node.js 22，用于构建 React 前端。
- 本地测试需安装 Ollama；正式演示需联网访问阿里云百炼新加坡业务空间。
- 端口：后端由 `.env` 中的 `APP_PORT` 配置，前端开发服务器默认为 `127.0.0.1:5173`。当前 Mac 正式演示使用 `APP_PORT=18000`，8000 只是可替换的示例值。

## 3 首次准备

1. 复制 `.env.example` 为 `.env`。`.env` 已被 Git 忽略，不得加入源码、论文附件或参赛包。
2. 不要把 `.env`、API Key、业务空间 ID、用户专属主机名或 URL 的截图放入参赛材料。
3. `frontend/public/models/haihe-girl.vrm` 已通过技术校验。运行 `uv run python scripts/validate_vrm.py frontend/public/models/haihe-girl.vrm` 可复核骨骼、眨眼、Aa 口型和作者元数据；公开发布前仍须取得书面授权并确认署名方式。
4. 执行 `uv sync --extra dev --extra docs`。
5. 进入 `frontend` 执行 `npm install`。

## 4 本地模型测试

```bash
ollama pull qwen3-embedding:4b
ollama pull qwen3.5:27b
uv run python -m backend.scripts.build_index
uv run pytest -q
uv run python -m backend.scripts.evaluate_retrieval
uv run python scripts/smoke_20_rounds.py
```

`.env` 中须保持 `GENERATION_PROVIDER=local` 和 `EMBEDDING_PROVIDER=local`。如果只进行单元测试，不需要启动模型服务；单元测试使用确定性的测试向量，不会冒充正式模型效果。

## 5 百炼正式配置

正式演示使用百炼新加坡业务空间。在本机 `.env` 填写密钥、Workspace ID 及业务空间接入地址；下面故意留空所有用户专属值：

```dotenv
GENERATION_PROVIDER=dashscope
EMBEDDING_PROVIDER=dashscope
DASHSCOPE_API_KEY=
DASHSCOPE_WORKSPACE_ID=
DASHSCOPE_REGION=ap-southeast-1
DASHSCOPE_API_HOST=
DASHSCOPE_COMPATIBLE_BASE_URL=
DASHSCOPE_NATIVE_BASE_URL=
DASHSCOPE_CHAT_MODEL=qwen3.7-flash-2026-07-15
DASHSCOPE_EMBEDDING_MODEL=qwen3.7-text-embedding
DASHSCOPE_EMBEDDING_DIMENSIONS=1024
TTS_PROVIDER=dashscope
DASHSCOPE_TTS_MODEL=qwen3-tts-flash-2025-11-27
DASHSCOPE_TTS_VOICE=Momo
DASHSCOPE_TTS_LANGUAGE=Chinese
```

`DASHSCOPE_API_HOST` 只填主机名，不带 `https://`。`DASHSCOPE_COMPATIBLE_BASE_URL` 用于对话和向量 OpenAI 兼容接口，`DASHSCOPE_NATIVE_BASE_URL` 用于非实时 HTTP TTS；两个显式 URL 优先于 API Host 和 Workspace ID 自动推导。这些用户专属值不得写入 `.env.example`。

修改嵌入模型后必须重新运行索引构建命令；程序会先建立临时索引，成功后再替换旧文件。当前生成和向量提供方已切换为 `dashscope`，新加坡生产索引已按 1024 维重建。不要在演示当天临时切换模型。

### 5.1 2026-09-13 生产链路实测

- 30 项后端单元/接口测试通过，包含扫描 PDF 的人工审核文本、页码引用、原 PDF 哈希保留以及百炼向量接口临时 403 重试覆盖。
- `qwen3.7-text-embedding` 1024 维向量调用成功，并已用同一配置重建包含 22 个来源、347 个知识块的生产索引。生产 60 题评测中，40/40 库内题在 Top-6 命中，20/20 越界、歧义和攻击题按规则拒答。
- `qwen3.7-flash-2026-07-15` 对话调用成功。
- 非实时 HTTP TTS `qwen3-tts-flash-2025-11-27` + `Momo` + `Chinese` 短句调用成功，返回 5.36 秒、24 kHz、单声道 WAV；新增风筝魏问题的完整问答—引用—语音链路返回 HTTP 200。
- 百炼正式 API 20 轮复测为 20/20 符合预期；其中 2 轮真实调用 `/api/speech`，均返回 HTTP 200。

这些结果证明当时配置的基础生产链路可用，不等于对云服务未来可用性或固定延迟的承诺。

## 6 启动方法

macOS：双击终端后在项目根目录运行 `./scripts/start_mac.sh`。

Windows PowerShell：运行 `powershell -ExecutionPolicy Bypass -File scripts/start_windows.ps1`。

当前 Mac 正式演示在 `.env` 中设置 `APP_PORT=18000`，然后使用 `./scripts/start_mac.sh`；该脚本会读取 `Settings().app_port`。也可手动执行，下方的 8000 只是示例：

```bash
cd frontend
npm run build
cd ..
uv run uvicorn backend.app.main:app --host 127.0.0.1 --port 8000
```

打开与 `APP_PORT` 一致的地址。当前 Mac 正式演示地址为 `http://127.0.0.1:18000`；若使用上述手动示例，则为 `http://127.0.0.1:8000`。顶部状态条显示索引、生成服务、语音服务与 VRM 是否就绪。

## 7 演示操作

1. 先点击“泥人张彩塑属于哪类国家级非物质文化遗产？”，展示正常检索、回答和引用。
2. 再点击服装设计问题，展示原创角色文档与历史资料被分开引用。
3. 点击“现在海河游船票多少钱”，展示系统因缺少实时证据而拒绝回答。
4. 演示提示词攻击问题，证明系统在检索前即停止处理。
5. 展开引用卡，展示来源标题、发布者、页码或官方网站链接。

## 8 故障处理

- 显示“索引尚未建立”：运行索引构建命令。
- 启动提示端口被占用：修改 `.env` 的 `APP_PORT`，重新运行启动脚本，并使用新端口打开浏览器。
- 显示“模型服务不可用”：本地模式检查 Ollama；正式模式检查新加坡地域、余额、Workspace ID、三个接入地址与网络。
- 回答正常但没有语音：检查百炼非实时 HTTP TTS 模型权限、`DASHSCOPE_API_KEY`、`DASHSCOPE_NATIVE_BASE_URL` 和 `Chinese` 语言配置。程序不会使用本地预录音代替。
- 显示“VRM 待导出”：确认模型文件名和路径完全为 `frontend/public/models/haihe-girl.vrm`，然后重新构建前端。
- 更换知识文件后：必须重新构建索引，避免数据库与来源文件哈希不一致。

## 9 安全与退出

服务只监听 `127.0.0.1`，不对公网开放。结束演示后按 `Control+C` 停止后端。提交前运行 `./scripts/check_submission.sh` 检查密钥、视频、PDF、VRM和文件大小。
