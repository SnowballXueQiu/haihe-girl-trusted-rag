# 海河少女项目运行环境说明

本文说明“海河少女”可信 RAG 虚拟主播项目的部署条件、环境变量和启动方法。命令均从项目根目录执行，前端依赖统一使用 `pnpm` 管理。

## 一、推荐部署方式

推荐使用“百炼生成 + 百炼向量 + 百炼语音”的单端口部署方式：先用 `pnpm` 构建 React 前端，再由 FastAPI 同时提供网页和 `/api` 接口。该方式不需要单独暴露 Vite 开发端口，适合 Linux 公网服务器、macOS 演示机和 Windows 演示机。

生产运行需要能够访问阿里云百炼新加坡业务空间。`.env` 中的 API Key、Workspace ID 和自定义服务地址属于敏感信息，只能保存在部署机器上，不得提交到 Git、截图、论文或参赛材料中。

## 二、基础环境

| 项目 | 要求 | 说明 |
| --- | --- | --- |
| 操作系统 | Linux、macOS 或 Windows 10/11 | 公网部署推荐 64 位 Linux |
| Python | 3.11 及以上 | 项目通过 `uv` 管理 Python 环境 |
| uv | 0.8 或更新版本 | 安装依赖、运行后端和构建索引 |
| Node.js | 22 LTS | 仓库 `.nvmrc` 指定版本 22 |
| pnpm | 10 或更新版本 | 安装及构建前端依赖 |
| 内存 | 百炼方案建议 4 GB 以上 | 本地 27B 模型需要显著更多内存或显存 |
| 磁盘 | 建议至少预留 2 GB | 不包含本地 Ollama 大模型所需空间 |
| 网络 | 可访问百炼业务空间 | 本地模型方案还需要本机 Ollama 服务 |
| 端口 | 默认 8000，可改为 18000 | 公网部署时需放行实际使用的 TCP 端口 |

Node.js 22 可使用 `nvm use 22` 切换。启用 pnpm：

```bash
corepack enable
corepack prepare pnpm@10.28.2 --activate
```

安装项目依赖：

```bash
uv sync --extra dev
pnpm --dir frontend install
```

## 三、创建环境配置

复制配置模板，不要直接修改 `.env.example`：

```bash
cp .env.example .env
chmod 600 .env
```

### 1. 推荐的百炼配置

将 `.env` 调整为以下形式。尖括号内容必须替换为实际值，不能连同尖括号原样保留。

```dotenv
APP_ENV=production
APP_HOST=0.0.0.0
APP_PORT=18000

GENERATION_PROVIDER=dashscope
GENERATION_MAX_ATTEMPTS=2
EMBEDDING_PROVIDER=dashscope

OLLAMA_BASE_URL=http://127.0.0.1:11434
OLLAMA_CHAT_MODEL=qwen3.5:27b
OLLAMA_EMBEDDING_MODEL=qwen3-embedding:4b

DASHSCOPE_API_KEY=<百炼 API Key>
DASHSCOPE_WORKSPACE_ID=<新加坡业务空间 Workspace ID>
DASHSCOPE_REGION=ap-southeast-1
DASHSCOPE_API_HOST=
DASHSCOPE_COMPATIBLE_BASE_URL=
DASHSCOPE_NATIVE_BASE_URL=
DASHSCOPE_CHAT_MODEL=qwen3.7-flash-2026-07-15
DASHSCOPE_EMBEDDING_MODEL=qwen3.7-text-embedding
DASHSCOPE_EMBEDDING_DIMENSIONS=1024

TTS_PROVIDER=dashscope
DASHSCOPE_TTS_MODEL=qwen3-tts-flash-2025-11-27
DASHSCOPE_TTS_VOICE=Momo
DASHSCOPE_TTS_LANGUAGE=Chinese

KNOWLEDGE_MANIFEST=knowledge/sources.json
RAG_INDEX_PATH=.data/index.sqlite
RETRIEVAL_TOP_K=6
RETRIEVAL_VECTOR_THRESHOLD=0.52
RETRIEVAL_LEXICAL_THRESHOLD=0.08
RETRIEVAL_ALLOW_LEXICAL_FALLBACK=false
STRICT_GROUNDING_VERIFICATION=true
```

在标准业务空间中，`DASHSCOPE_API_HOST`、`DASHSCOPE_COMPATIBLE_BASE_URL` 和 `DASHSCOPE_NATIVE_BASE_URL` 保持为空即可，程序会根据 Workspace ID 和 Region 生成地址。若百炼控制台提供了专属地址，则按控制台信息填写：

- `DASHSCOPE_API_HOST` 只填写主机名，不带 `https://`。
- `DASHSCOPE_COMPATIBLE_BASE_URL` 填兼容 OpenAI 接口的完整基础 URL。
- `DASHSCOPE_NATIVE_BASE_URL` 填百炼原生 HTTP 接口的完整基础 URL。
- 两个显式 Base URL 的优先级高于 `DASHSCOPE_API_HOST`，通常不要同时填写多套地址。

### 2. 本地 Ollama 配置

如需在本机运行生成模型和向量模型，将以下字段改为 `local`：

```dotenv
GENERATION_PROVIDER=local
EMBEDDING_PROVIDER=local
OLLAMA_BASE_URL=http://127.0.0.1:11434
OLLAMA_CHAT_MODEL=qwen3.5:27b
OLLAMA_EMBEDDING_MODEL=qwen3-embedding:4b
```

并提前安装模型：

```bash
ollama pull qwen3.5:27b
ollama pull qwen3-embedding:4b
```

当前项目没有离线语音合成后备方案。即使生成和向量使用 Ollama，若需要语音播报，仍须填写百炼的 `DASHSCOPE_API_KEY`、`DASHSCOPE_WORKSPACE_ID` 和 TTS 配置；未配置时文本问答可以运行，但语音服务不会就绪。

## 四、环境变量完整说明

| 变量 | 是否必填 | 建议值或用途 |
| --- | --- | --- |
| `APP_ENV` | 建议 | 本地填 `development`，服务器填 `production` |
| `APP_HOST` | 建议 | 本机访问填 `127.0.0.1`，公网监听填 `0.0.0.0` |
| `APP_PORT` | 是 | 服务端口，如 `8000` 或 `18000` |
| `GENERATION_PROVIDER` | 是 | `local` 或 `dashscope` |
| `GENERATION_MAX_ATTEMPTS` | 是 | 生成与复核最大尝试次数，允许 1 至 3，推荐 `2` |
| `EMBEDDING_PROVIDER` | 是 | `local` 或 `dashscope`，必须与索引中的向量来源一致 |
| `OLLAMA_BASE_URL` | 本地方案必填 | Ollama 地址，默认 `http://127.0.0.1:11434` |
| `OLLAMA_CHAT_MODEL` | 本地生成必填 | 默认 `qwen3.5:27b` |
| `OLLAMA_EMBEDDING_MODEL` | 本地向量必填 | 默认 `qwen3-embedding:4b` |
| `DASHSCOPE_API_KEY` | 百炼或语音必填 | 百炼 API Key，禁止提交或公开 |
| `DASHSCOPE_WORKSPACE_ID` | 百炼或语音必填 | 新加坡业务空间 ID，禁止提交或公开 |
| `DASHSCOPE_REGION` | 百炼方案必填 | 当前使用 `ap-southeast-1` |
| `DASHSCOPE_API_HOST` | 可选 | 专属主机名，不带协议；无专属地址时留空 |
| `DASHSCOPE_COMPATIBLE_BASE_URL` | 可选 | 兼容 OpenAI 接口完整基础 URL，填写后优先使用 |
| `DASHSCOPE_NATIVE_BASE_URL` | 可选 | 原生 HTTP 接口完整基础 URL，语音合成使用 |
| `DASHSCOPE_CHAT_MODEL` | 百炼生成必填 | 当前固定快照为 `qwen3.7-flash-2026-07-15` |
| `DASHSCOPE_EMBEDDING_MODEL` | 百炼向量必填 | 当前为 `qwen3.7-text-embedding` |
| `DASHSCOPE_EMBEDDING_DIMENSIONS` | 百炼向量必填 | 当前索引使用 `1024` 维 |
| `TTS_PROVIDER` | 需要语音时必填 | 当前只支持 `dashscope` |
| `DASHSCOPE_TTS_MODEL` | 需要语音时必填 | `qwen3-tts-flash-2025-11-27` |
| `DASHSCOPE_TTS_VOICE` | 需要语音时必填 | 当前音色为 `Momo` |
| `DASHSCOPE_TTS_LANGUAGE` | 需要语音时必填 | 中文使用 `Chinese` |
| `KNOWLEDGE_MANIFEST` | 是 | 知识来源清单，默认 `knowledge/sources.json` |
| `RAG_INDEX_PATH` | 是 | SQLite 索引位置，默认 `.data/index.sqlite` |
| `RETRIEVAL_TOP_K` | 是 | 返回候选数，范围 1 至 12，当前使用 `6` |
| `RETRIEVAL_VECTOR_THRESHOLD` | 是 | 向量检索阈值，当前使用 `0.52` |
| `RETRIEVAL_LEXICAL_THRESHOLD` | 是 | FTS5 词法检索阈值，当前使用 `0.08` |
| `RETRIEVAL_ALLOW_LEXICAL_FALLBACK` | 是 | 是否允许仅词法证据继续生成，正式演示使用 `false` |
| `STRICT_GROUNDING_VERIFICATION` | 是 | 是否启用独立语义复核，正式演示使用 `true` |

## 五、构建知识索引

首次部署必须构建索引：

```bash
uv run python -m backend.scripts.build_index
```

更改 `EMBEDDING_PROVIDER`、向量模型或向量维度后，必须重新执行该命令。生产百炼索引与本地 Ollama 索引不能混用；若状态接口返回 `index_mismatch`，说明当前 `.env` 与已有索引不一致。

## 六、构建与启动

构建前端：

```bash
pnpm --dir frontend build
```

仅本机访问时：

```bash
uv run uvicorn backend.app.main:app --host 127.0.0.1 --port 18000
```

公网服务器运行时：

```bash
uv run uvicorn backend.app.main:app --host 0.0.0.0 --port 18000
```

浏览器打开 `http://服务器地址:18000/`。FastAPI 会直接提供 `frontend/dist` 中的页面，因此不需要另外启动 `pnpm dev`。若使用 Vite 开发服务器，其 `/api` 代理固定指向 `127.0.0.1:8000`，后端也应临时使用 8000 端口。

使用 tmux 持续运行：

```bash
tmux new -s haihe-girl
uv run uvicorn backend.app.main:app --host 0.0.0.0 --port 18000
```

按 `Ctrl+B` 后再按 `D` 退出会话但保持服务运行。重新进入：

```bash
tmux attach -t haihe-girl
```

公网部署还需在云平台安全组或系统防火墙中放行实际端口。长期公开服务建议使用 Nginx/Caddy 配置 HTTPS 反向代理，不要公开 `.env`、`.data` 或项目目录列表。

## 七、运行检查

检查服务状态：

```bash
curl http://127.0.0.1:18000/api/health
```

正常演示时应重点确认：

- `status` 为 `ready`。
- `model_ready`、`embedding_ready`、`speech_ready` 和 `vrm_ready` 均为 `true`。
- `demo_ready` 为 `true`。

代码测试和前端构建检查：

```bash
uv run pytest -q
pnpm --dir frontend build
```

## 八、常见问题

- `index_missing`：运行索引构建命令。
- `index_mismatch`：当前向量提供方、模型或维度与索引不一致，重新构建索引。
- `DASHSCOPE_API_KEY 尚未配置`：检查 `.env` 是否位于项目根目录，变量名是否正确。
- 问答可用但不能播报：检查 TTS 模型、音色、余额、业务空间权限和网络连通性。
- VRM 未就绪：确认 `frontend/public/models/haihe-girl.vrm` 存在，然后重新构建前端。
- 页面能打开但接口失败：确认浏览器访问的是 FastAPI 端口，或确保 Vite 代理与后端端口均为 8000。
- 端口被占用：更换 `.env` 中的 `APP_PORT`，并同步修改实际 `uvicorn --port` 参数和防火墙规则。
- 公网无法访问：确认使用 `--host 0.0.0.0`，并检查安全组、防火墙及端口映射。

部署完成后不要将 `.env`、终端中的密钥、带签名的临时语音 URL 或百炼控制台截图放入提交材料。
