# 张明山与泥人张

澎湃新闻文章介绍，“泥人张”最初是对天津泥塑艺人张明山（1826—1906）的称号。张明山后来创办塑古斋，其后人持续传承并结合时代审美进行创新，使“泥人张”逐渐成为天津老字号和北方泥塑的重要代表。文章把泥人张的发展放在天津漕运、庙会、市民文化和戏曲生活的背景中理解，这一叙事可补充国家非遗项目资料。

# 艺术特征

文章概括泥人张彩塑重视人物动态、神情和生活气息，常以戏曲人物、历史故事和市井生活为题材。制作强调手工塑形，常使用柳叶状“压子”辅助刻画，并讲究塑形和彩绘之间的配合。文章还讨论了张玉亭等后继者对普通劳动者和市民生活题材的表现。具体单件作品名称、年代和馆藏信息仍应以博物馆藏品说明为准。
