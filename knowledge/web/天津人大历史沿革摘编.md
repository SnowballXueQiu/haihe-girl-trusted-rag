# 天津历史沿革

天津市人大页面记载，天津简称津，也称津沽、津门。天津地区商周时期已有人类居住；隋朝大运河开通后地位上升，唐朝中叶以后成为南方粮、绸北运的水陆码头。金代在南北运河与海河交汇的三岔河口一带设直沽寨，元延祐三年（1316）改为海津镇。明永乐二年（1404）设天津卫，此后又设左卫、右卫。清代三卫合一，后经历天津州、天津府等建置变化。

# 近代发展

页面记载，1860年天津开埠后成为中国北方开放前沿和洋务运动基地，铁路、电报、邮政、采矿、近代教育等事业发展。1949年1月15日天津解放；改革开放后，天津作为沿海港口城市继续发展。该政府页面用于核对城市名称和历史时间线，不用于回答实时政策或统计数据。来源网址：https://www.tjrd.gov.cn/tjfq/system/2019/04/24/030012411.shtml
