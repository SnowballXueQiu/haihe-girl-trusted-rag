# 第1页

谭徐明《海河流域水环境的历史演变及其主要影响因素研究》发表于《水利发展研究》2002年第12期。文章指出，近两千年间海河流域下游河道、湖泊和洼淀变化显著，变化受黄河改道、运河开凿、河道决口及地形地貌共同影响。海河水系的形成与卫河、南运河以及隋唐以来的运河利用密切相关。文章将华北平原河流特征概括为多沙、善徙和悬河，并说明这些特征是在长期自然变化和人类活动中逐步形成的。

# 第2页

文章回顾冀中和渤海凹陷西北部湖沼洼淀的缩减过程，指出秦汉以来泥沙沉积、围垦和水利调控不断改变水面范围。白洋淀位于永定河与滹沱河冲积扇之间，历史上由多个淀泊相连形成，宋代曾因防御和水利措施扩大，之后又逐渐缩小。20世纪地下水工业化开采扩大，尤其是农业机井快速增加后，深浅层地下水超采加剧，并出现地下水位降落漏斗。

# 第3页

论文把地下水超采的后果概括为水位下降、地面沉降、海水或咸水入侵、湿地与地表水体干化以及水质下降。文章同时讨论降水、气温、海平面和地质地貌等自然因素，认为湖泊盈缩与气候有关，但仅用气候变化不足以解释历史时期水环境的大幅变化。作者据长时间序列资料判断，人类活动在近代水环境变化中的作用需要与自然因素共同考察。

# 第4页

文章认为，黄河长期北流和后来南徙对海河南系河流、古河道、地下水汇集带及平原微地貌产生了重要影响。与自然因素相比，人口增长、耕地需求、木材采伐和水资源开发对水环境的压力更加直接。明清以来燕山、太行山植被破坏加剧水土流失，泥沙进入下游河道后增加淤积和洪涝风险。资料中的历史统计是研究结论，应注明论文年代，不应用于推断当前实时水文状况。

# 第5页

论文将水利建设影响分为先秦至汉代、三国至唐宋、元明清以及现代阶段。堤防、疏浚和运河工程能够稳定河道、保障漕运和防洪，但也可能改变泥沙输移、淀泊蓄滞洪水空间及土地利用。清代对永定河和大清河水系的治理体现了河道稳定与淀泊淤积之间的权衡；围垦又进一步压缩湖淀面积，形成社会经济发展、防洪需求与水环境保护之间的矛盾。

# 第6页

文章指出，20世纪50年代以后水库建设、城市扩张、农业灌溉和地下水开采显著改变了海河流域整体水环境。水利工程保障了城市供水、工农业用水与防洪安全，但持续增长的用水需求也带来河流断流、淀泊缩减、地下水超采和污染下渗等问题。作者的结论是：近两千年的气候变化不能单独解释流域演变，元代以来的人口与开发活动、特别是近现代高强度开发，是水环境快速变化的重要因素；修复需要水利措施与产业、用水政策共同配合。
